# Kumo · 雲朵湊一湊 ☁️

A cute Japanese-style web game for kindergarten kids to master **number pairs that make 8 and 9** — zero props, pure screen play. Perfect for classroom projection, online lessons, or tablets.

日式可愛風線上互動遊戲，專練「8 和 9 的組合」。無道具、純屏幕互動，老師投屏一點即玩。

🎮 **Play it:** https://artzdesignmo.github.io/kumo/

## Game modes · 玩法

| Mode | What kids do |
|---|---|
| ☁️ 湊成 8 / Make 8 | Tap two clouds — do they add up to 8? Chant: 對對對！ |
| 🌈 湊成 9 / Make 9 | Same game, new target: 9 |
| ⚡ 極速挑戰 / Speed Round | 60 seconds — can these two clouds make the target? Hit ⭕ / ❌ |
| 🧩 缺雲朵填空 / Fill the Blank | `2 + ( ? ) = 8` — which cloud is missing? |
| 💣 炸彈陷阱 / Bomb Trap | Dodge the bomb clouds, find the pair that makes 8 or 9 |

Classroom chant built in: 先看總數、再找朋友 *(look at the target first, then find its friend)*.

## Features

- 🎨 Kawaii pastel sky, smiling clouds, synthesized sound effects (no audio files)
- 🌐 繁中 / EN toggle · ☀️ white / silver / black themes (saved in localStorage)
- 📱 Big touch targets — projector, tablet and phone friendly
- 📦 Single HTML file, vanilla JS, zero dependencies

## Tech

HTML5 · CSS3 · Vanilla JS (ES6) · WebAudio API · Google Fonts (Huninn, M PLUS Rounded 1c, Noto Sans TC)
